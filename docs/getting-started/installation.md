# Installation

Download and install Zelcore on your preferred platform. Zelcore is available for desktop, mobile, and as a browser extension.

## Desktop

Zelcore Desktop is available for Windows, macOS, and Linux.

### System Requirements

- **Windows**: Windows 10 or later (64-bit)
- **macOS**: macOS 10.13 (High Sierra) or later
- **Linux**: Ubuntu 18.04 or later, Fedora 32 or later

### Download Desktop

1. Visit the [ZelCore desktop wallet](https://zelcore.io/wallet) download page
2. Select your operating system (Windows, macOS, or Linux)
3. Run the installer once downloaded
4. Follow the installation prompts

:::tip
The desktop version offers the most comprehensive feature set, including FluxNode management and advanced trading tools.
:::

## Mobile

Access Zelcore on the go with the [ZelCore mobile wallet](https://zelcore.io/mobile-wallet) for iOS and Android.

### iOS

**Requirements**: iOS 13.0 or later

1. Open the **App Store** on your iPhone or iPad
2. Search for **"Zelcore"**
3. Tap **Get** to download and install
4. Open the app once installation is complete

[Download on App Store →](https://apps.apple.com/app/zelcore/id1436296839)

### Android

**Requirements**: Android 8.0 or later

1. Open **Google Play Store** on your Android device
2. Search for **"Zelcore"**
3. Tap **Install**
4. Open the app once installation is complete

[Get it on Google Play →](https://play.google.com/store/apps/details?id=com.zelcash.zelcore)

## Browser Extension

Use the [ZelCore browser extension](https://zelcore.io/browser-extension) directly in your web browser for seamless Web3 integration.

### Supported Browsers

- Chrome
- Firefox
- Edge
- Brave

### Installation Steps

1. Visit the Chrome Web Store or your browser's extension marketplace
2. Search for **"Zelcore"**
3. Click **Add to [Browser Name]**
4. Confirm the installation
5. The Zelcore icon will appear in your browser toolbar

:::info
The browser extension is ideal for interacting with DeFi applications and NFT marketplaces via WalletConnect.
:::
