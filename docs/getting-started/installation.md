# Installation

Zelcore is available as a desktop app, a mobile app and a browser extension. This page lists the official download for each, with the system requirements.

:::info Applies to Zelcore 8.39
System requirements match Zelcore 8.39.0 on desktop, mobile and the extension (October 2026).
:::

:::warning Install only from the official links on this page
Use the links below or go to [zelcore.io/wallet](https://zelcore.io/wallet). Do not install Zelcore from search results, ads, social media posts, messages, or third-party download sites. Fake wallet apps exist, and they are built to steal your seed phrase.
:::

Background: [Zelcore Setup: First-Time Wallet Guide (2026)](https://zelcore.io/academy/how-to/setting-up-zelcore-first-time)

## How to spot an impostor

- **A real Zelcore app never needs your seed phrase to install or open.** Enter a seed phrase only when you create or import a wallet inside the app you installed from an official source. If an installer, a website or a support agent asks for it, stop.
- **Check the address.** Start desktop downloads from `zelcore.io/wallet`. The mobile and extension links below point to the official store listings. Open them from this page, then compare the listing ID in the address bar with the ID shown in the steps.
- **Be careful with search results.** Search results can include sponsored listings and look-alike apps. Reach the store listing from a link on zelcore.io or this page instead.
- **Zelcore will never ask for your seed phrase, password or private keys.** Anyone who asks for them is not Zelcore.

If you already installed something that does not come from an official link, and you entered a seed phrase, see [Responding to a Wallet Compromise](/docs/guides/responding-to-wallet-compromise).

## Desktop

Download the desktop app from [zelcore.io/wallet](https://zelcore.io/wallet). It is free.

### System requirements

| Operating system | Requirement | Builds |
| --- | --- | --- |
| Windows | Windows 10 or later | Installer or portable |
| macOS | macOS 12 (Monterey) or later | Apple Silicon and Intel |
| Linux | x64 | `.deb` and `.AppImage` |

### Install on Windows

1. Download the Windows build from [zelcore.io/wallet](https://zelcore.io/wallet). Choose the installer, or the portable build if you do not want to install anything.
2. For the installer, run it and follow the prompts. For the portable build, save the .exe where you want it and run it.

Windows 7 and 8 are not supported. For the full Windows walkthrough, see [Zelcore for Windows: Download and Setup](/docs/guides/zelcore-windows-setup).

### Install on macOS

1. Download the build that matches your Mac from [zelcore.io/wallet](https://zelcore.io/wallet): Apple Silicon (M1 and later) or Intel.
2. Open the downloaded file and follow the prompts.

To see which chip your Mac has, open the Apple menu and choose **About This Mac**.

### Install on Linux

1. Download the `.deb` or the `.AppImage` from [zelcore.io/wallet](https://zelcore.io/wallet) (x64 builds).
2. For the `.deb`, install it with your package manager, for example `sudo apt install ./<file>.deb`. For the `.AppImage`, make it executable (`chmod +x <file>.AppImage`) and run it.

:::tip
The desktop app has the most complete feature set, including FluxNode management, and it is the only version that works with Ledger and Trezor hardware wallets.
:::

If the installer does not start or the app will not open, see [Troubleshooting App Installation](/docs/guides/troubleshooting-app-installation).

## Mobile

The [Zelcore mobile wallet](https://zelcore.io/mobile-wallet) is available for iOS and Android from the official stores.

### iOS

**Requirements**: iOS 15 or later.

1. On your iPhone or iPad, open the official listing: [Zelcore on the App Store](https://apps.apple.com/app/zelcore/id1436296839).
2. Check that the address contains `id1436296839`.
3. Check the developer: Influx Technologies Limited on the App Store.
4. Tap **Get**, then open the app after it installs.

### Android

**Requirements**: Android 8.0 or later.

1. On your Android device, open the official listing: [Zelcore on Google Play](https://play.google.com/store/apps/details?id=com.zelcash.zelcore).
2. Check that the address contains `id=com.zelcash.zelcore`.
3. Check the developer: Influx Technologies USA on Google Play.
4. Tap **Install**, then open the app after it installs.

## Browser extension

The [Zelcore browser extension](https://zelcore.io/browser-extension) works in Chrome, Brave and Edge. All three use the same Chrome Web Store listing. Firefox is not supported.

1. Open the official listing: [Zelcore on the Chrome Web Store](https://chromewebstore.google.com/detail/zelcore/khpdakhaigcopakcondjleibgpdjpmck).
2. Check that the address ends with `khpdakhaigcopakcondjleibgpdjpmck`.
3. Click **Add to Chrome** (or the button for your browser) and confirm.
4. Pin the Zelcore icon in your browser toolbar.
