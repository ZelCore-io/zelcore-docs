# About These Docs

These docs are the Zelcore knowledge base: setup guides, walkthroughs, troubleshooting and FAQs for the Zelcore wallet on desktop, mobile and as a browser extension.

## Who maintains them

The Zelcore team maintains these docs.

## How pages are kept accurate

Pages are checked against the current app release. Each page shows a "Last updated" date. Pages whose steps or screens depend on the app version say which version they apply to, near the top of the page. As of October 2026, that is Zelcore 8.39.0.

If a page shows screenshots from an earlier version, it says so.

## Report an error

If something here is wrong or out of date, tell us in either of these ways:

- Use the **Edit this page** link at the bottom of the page. It opens the page on GitHub.
- Contact [Zelcore support](https://support.zelcore.io).

## Concepts and news

Background explainers and release news are on the [Zelcore Academy](https://zelcore.io/academy). These docs focus on how to do things in the app.

## Official downloads

Official download links are on the [Install Zelcore](/docs/getting-started/installation) page and on zelcore.io ([/wallet](https://zelcore.io/wallet), [/mobile-wallet](https://zelcore.io/mobile-wallet), [/browser-extension](https://zelcore.io/browser-extension)).
